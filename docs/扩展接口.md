# 扩展接口

本文档说明 `dice-host` 向 Dice! 模块和脚本提供的扩展功能。

## askExtra

Dice! 的 Lua 函数 `askExtra` 会将参数交给驱动处理。`dice-host` 将其转换为 OneBot API 调用，并返回调用结果。

### 调用方式

参数可以放在 `params` 中：

```lua
local r = askExtra({action = "get_group_info", params = {group_id = msg.gid}})
if r.status == "ok" then
    return r.data.group_name
end
```

也可以与 `action` 平级书写：

```lua
askExtra({action = "send_like", user_id = msg.uid, times = 10, async = true})
```

未应用补丁 `0002-askextra-table-to-json` 的核心无法正确传递 table 参数，此时应传入 JSON 字符串：

```lua
askExtra('{"action":"group_poke","params":{"group_id":' .. msg.gid .. ',"user_id":' .. msg.uid .. '}}')
```

### 参数

| 参数 | 说明 |
|---|---|
| `action` | OneBot API 名称，必填 |
| `params` | API 参数。省略时，除 `action`、`async`、`timeout` 外的其余字段均作为参数 |
| `async` | 为 `true` 时不等待调用结果，立即返回 |
| `timeout` | 超时时间（毫秒），默认使用配置项 `rpc_timeout_ms` |

### 返回值

| 字段 | 说明 |
|---|---|
| `status` | `ok`、`failed` 或 `async` |
| `retcode` | OneBot 返回码 |
| `data` | OneBot 返回的数据 |
| `message` | 错误信息，仅在出错时存在 |

### 内置动作

| 动作 | 说明 |
|---|---|
| `napdice_info` | 返回驱动版本、骰娘账号及连接状态 |
| `getGender` | 由核心在解析 `{gender}` 时调用，返回 `男`、`女` 或 `未知` |

## 事件

### Poke

配置项 `forward_poke` 为 `true`（默认）时，戳一戳通知会以 `Poke` 事件传给核心。事件字段如下：

| 字段 | 说明 |
|---|---|
| `uid` | 发起戳一戳的用户 |
| `target` | 被戳的用户 |
| `gid` | 群号，私聊时不存在 |
| `time` | 事件时间 |

骰娘本人发起的戳一戳不会触发该事件。

示例：

```toml
# mod/example/event/poke.toml
[event.on_poke]
title = "戳一戳"
trigger.hook = "Poke"
action.lua = "on_poke"
```

```lua
-- mod/example/script/on_poke.lua
if event.target == tonumber(getDiceQQ()) then
    if event.gid then
        sendMsg("别戳了", event.gid, 0)
    else
        sendMsg("别戳了", 0, event.uid)
    end
end
```

### OneBotNotice 与 OneBotRequest

配置项 `forward_notice` 为 `true` 时，`dice-host` 未单独处理的通知和请求会分别以 `OneBotNotice`、`OneBotRequest` 事件传给核心。

`OneBotNotice` 包含 `notice_type`、`sub_type`、`uid`、`gid` 字段，以及字符串形式的原始事件 `raw`。

`OneBotRequest` 包含 `request_type`、`sub_type`、`uid`、`gid`、`flag`、`comment` 字段。

## 图片、语音与文件

回复中的 `[CQ:image,file=...]`、`[CQ:record,file=...]` 若使用相对路径，`dice-host` 按以下顺序查找文件：

1. `root_dir/data/image`（语音为 `root_dir/data/record`）
2. `root_dir`
3. `root_dir/Dice{QQ号}`

找到后改为绝对路径发送。模块中 `image`、`audio` 目录下的文件由核心复制到上述第 1 项所列目录。

配置项 `media_base64` 为 `true` 时，图片、语音以及上传的文件改为以 base64 编码发送。NapCat 与 `dice-host` 不在同一台机器上，或 NapCat 运行于容器中时，需要开启此项。

## 消息格式转换

`dice-host` 在收发消息时会做以下转换：

- 发送时，将 `[CQ:at,id=...]` 改写为 NapCat 支持的 `[CQ:at,qq=...]`；
- 接收时，将 `[CQ:at,qq=...,name=...]` 简化为 `[CQ:at,qq=...]`；
- 配置项 `strip_reply` 为 `true` 时，移除消息开头的 `[CQ:reply,...]`。
